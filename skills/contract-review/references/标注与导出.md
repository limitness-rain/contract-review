# 标注与导出

以下字段和校验用于初标、复核、Excel 导出和飞书交付。

先将合同交易角色映射到正式规则立场，对照全文和有效附件判断适用前提、触发和排除条件。正文按一级标题及其下全部内容切片，前言、前后签署页不进标注切片。一级条款内的表格完整留在同一切片，保留单元格及换行结构。关联条款原文同样取完整一级切片。

## 按规则选择标注路径

| 规则和合同情况 | 生成什么记录 | 相关性 | 是否触发该风险 | 条款原文和关键证据 |
| --- | --- | --- | --- | --- |
| 只检查已有条款 | 每个正文切片 × 每条适用规则 × 对应立场。相关与不相关记录都保留 | 相关填是，不相关填否 | 相关时按规则判断。常规不相关行填否 | 都填对应的完整主切片。相关时摘录支持结论的原文。常规不相关时证据留空 |
| 只查全文是否缺少约定，已有主条款 | 对实际需要标注的相关切片分别填。根据规则及全文判定，并核对现有条款是否少了规则要求的具体内容 | 是 | 缺失条件未触发填否。规则明确某一必要约定欠缺也可触发时，按具体条件判断 | 原文填实际完整切片。有支持判断的原文就摘录 |
| 只查全文是否缺少约定，且无主条款 | 一合同 × 一规则 × 一立场，按审查事项独立记录 | 否 | 明确满足缺失触发条件且未排除填是。依据规则可确认不适用或有排除条件时填否 | 主条款类型、条款原文、关键证据留空 |
| 同一规则同时查全文缺失和已有条款触发 | 对同一个审查事项先判主条款是否存在。有主条款走切片分支，无主条款走独立全文缺失分支。规则含相互独立的事项时分别判断 | 按走到的分支 | 按走到的分支 | 按走到的分支 |

不以文件空白、没有标注或看不到材料直接判有/无风险。有主条款但其中少了某项条件时，依据具体规则判断；保留存在的条款和支持判断的证据。关联条款可以作为理解全文的依据；关键证据只摘本行主切片的原文字句，保留条件、对象、范围和后果，多个摘录用空行隔开。相关且无风险也要摘录支持结论的原文，确实没有可摘录原文时留空。全文缺失卡是合同级记录，页面对照合同全文与附件，并保留判断依据或意见，不构造主切片。

## 15 个字段怎么显示、怎么填

实习生、律师和验收均可查看和筛选五类卡片。先看主条款原文，再看相关性和触发结论。

| 卡片类型 | 主条款 | 相关性 | 触发 | 关键证据、关联条款和处理意见 |
| --- | --- | --- | --- | --- |
| 相关，触发风险 | 有，填完整原文和类型 | 是 | 是 | 摘录直接支持触发的主条款原文，填写风险说明和修订建议。有关联时填写完整关联条款及其类型、属性。 |
| 相关，未触发风险 | 有，填完整原文和类型 | 是 | 否 | 摘录支持未触发的主条款原文，确无可摘录时留空。可保留支持判断的关联条款。风险说明和修订建议留空。 |
| 全文无主条款，缺失触发 | 原文和类型留空 | 否 | 是 | 关键证据留空。可记录支持适用前提或缺失判断的关联条款。说明缺失约定、后果和可补入的条文。 |
| 全文无主条款，缺失未触发 | 原文和类型留空 | 否 | 否 | 关键证据、风险说明及修订建议留空。可记录说明适用前提不成立或排除条件成立的关联条款。 |
| 普通切片与规则不相关 | 有，填完整原文和类型 | 否 | 否 | 关键证据、三项关联条款字段、风险说明和修订建议留空。 |

普通不相关切片默认收起，选中对应风险类型时才列出。其余分类及「判断待核对」可在「全部类型」中查看。旧包的字段原值保留，详情会提示应留空的字段。实习生提交和律师导出终版前，均需确认前四类卡片。普通不相关切片无需确认，仍随 ZIP 保存。已有终版按原确认口径验收。绑定合同、规则和主切片后，六个来源字段自动带出并只读。标准表有以下 15 列。

| 导出字段 | 网页位置 | 填值 |
| --- | --- | --- |
| 合同附件名称 | 合同附件选择及字段详情 | 实际用于标注的合同文件名，保留扩展名 |
| 条款类型 | 编辑标注字段 | 填 V1 中文分类名称，省去编号。独立全文缺失卡留空 |
| 条款原文 | 左侧合同原文 | 完整一级切片。独立全文缺失卡留空 |
| 风险名称 | 卡片标题及规则 | 正式规则原值，沿用同名同立场的正确规则 |
| 立场 | 卡片标题及规则 | 合同交易角色对应的正式规则立场 |
| 条款与规则是否相关 | 随卡片操作保存 | 是／否 |
| 是否触发该风险 | 随卡片操作保存 | 是／否 |
| 风险等级 | 卡片标题及规则 | 正式规则原值，无风险也填写 |
| 审查逻辑 | 字段详情及规则 | 完整沿用正式规则该字段，包括前提、触发和排除等原文 |
| 关联条款类型 | 关联条款 | 有关联才填，与主条款使用同一份 V1 中文分类名称 |
| 关联条款属性 | 关联条款 | 有关联才填。使用「引用、例外、生效条件、定义来源、优先适用」之一 |
| 关联条款原文 | 关联条款 | 有关联才填。完整关联一级切片；多条可分行，其余字段一致 |
| 风险判断关键证据 | 卡片及左侧高亮 | 有主条款且相关时摘录。普通不相关切片及两类全文缺失记录留空 |
| 风险说明 | 卡片 | 触发时说明为何触发、影响谁及后果。未触发时留空 |
| 修订建议 | 卡片 | 触发时给出可写入合同的条文。未触发时留空 |

**某份合同没有触发某条风险**，仍按它应走的路径输出上面对应的「风险否」记录，并填写存在且适用的字段。**某条规则完全没有记录**，需要先按该合同、规则立场和应有的切片/全文路径查覆盖。确认漏标后补上应填的记录，不用空表行或杜撰主条款凑数。

## 四项校验

1. **固定格式。** 核附件名、二元字段、一级切片边界、主切片内证据、中文分类及关系。检查报告要区分缺失独立行和常规切片。依据明确的格式问题可修正，提示具体记录。
2. **专家规则原值。** 逐项比对风险名称、等级、审查逻辑；复核实际交易角色与规则立场映射。发现多填、漏填、改名或规则版本不一致时列出源值。规则归属不明确时先找正式来源。
3. **合同全文和规则判断。** 审查对象、适用前提、关联约定、触发及排除条件都要对照全文与已有附件。分别核对「相关性、是否触发、关键证据」。提示证据虽然来自原文却不支撑当前判断的记录。以真实全文和正式规则为依据，优先核实相关性、触发结论和证据是否相互支持。保留具体依据和审阅意见。
4. **漏标、重复和预埋后同步。** 先画出合同 × 适用规则/立场 × 判断路径的覆盖清单。再检查漏切片、漏规则/立场、重复记录和合法的关联条款拆行。预埋后检查原始与评测附件分开、正文哈希和实际版本一致，证据和标注以最后版本为准，并按不同合同重算正例。

## 终版 Excel

从律师终版 ZIP 导出一个名为「标注集」的工作表。最终确认的双原文删卡从 Excel 移除对应记录；单原文删卡按不相关、未触发保留，理由和源记录随 ZIP 保存。普通未触发和不相关记录仍按覆盖规则保留。同一合同、规则、事项及切片补标后，被新增风险卡替代的旧不相关标注保留在 ZIP 的来源和操作历史中，Excel 输出当前有效记录。

双原文仅在原文一致且初标可准确配对时共用一张复核卡。用于比较的字段除附件名称和立场外必须一致，包括审查逻辑。同名风险不自动合并。共用卡的改动同步到两条来源，Excel 分别保留各自的附件全名和立场；律师最终确认删除时移除这两行。

## 飞书交付与回读

按[Codex 工作流](./Codex工作流.md#律师终版预检)预检，等待用户明确指定飞书位置和操作范围。目标和范围确认后按 SOP 新建目标表，用户明确指定已有表时按其授权范围处理。数据表命名为「标注集」，按字段名映射，列序与上表一致。两个判断字段是只含「是」「否」的单选，其余为文本。

导入后回读实际表格，核对列名、列序、类型、选项和行数，并逐记录与律师终版核对原文、证据、换行、合法空值和本轮改动。修复导入产生的问题后再次回读。源数据疑点列出合同、行号、字段、现值和依据，保留律师确认的值。交付新表链接、回读结果和问题清单；受权限限制时交付 Excel 及阻塞原因。复核意见、问答和操作历史随终版 ZIP 保存。
