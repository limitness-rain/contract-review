# 合同标注复核工具

从「二轮规则优化」读取合同与标注集，生成初始复核 ZIP。需要补充评测样本时，Codex 可按双方正式规则准备风险预埋材料。实习生、律师和最终验收共用固定的合同复核工具，用 ZIP 交接，最终可导出 15 列 Excel。

## 在 Codex 中使用

- **从 GitHub 安装 Skill**。把下面这句话发给 Codex，安装完成的回复会带上使用提示。接着可直接说合同类型或发复核 ZIP，也可调用 `$contract-review`。

  > 请用 `$skill-installer` 从 https://github.com/limitness-rain/contract-review 的 `skills/contract-review` 安装 `contract-review`。安装成功后，读取该 Skill 的「开场」并在当前回复中告诉我三种主要用法。

  Skill 在仓库的 `skills/contract-review` 目录。直接运行安装脚本时，用仓库首页 URL 搭配 `--path skills/contract-review`。仓库为私有时，使用有访问权限的 GitHub 账号。
- **把工具 ZIP 交给 Codex**。在可访问本机文件和终端的 Codex 中提供 ZIP，告诉 Codex「解压并使用其中的 contract-review 技能，复核保管合同」。也可以把解压目录直接作为 Codex 工作区。工具 ZIP 与每个批次的复核 ZIP 各有用途。
- **用自己准备的材料建包**。在 Codex 对话中上传材料文件夹，或上传实际用于标注的 Word 和标注 Excel。确认本次使用上传材料后，Codex 核对版本并分别给出固定网页和初始 ZIP。[本地材料工作流](./skills/contract-review/references/Codex工作流.md#用上传的本地材料生成初始-zip)
- **离线手动处理**。双击 [合同复核工具.html](./合同复核工具.html)，导入复核数据 ZIP，或从本地 Word 与 Excel 建包。

工具需要 Python 3.9+、Node.js 和 Chrome 或 Edge。走飞书取件或写入时，使用当前机器的 `lark-cli` 登录身份，授权由本人在本机完成。仓库没有账号凭据、真实合同、标注集或交接包。

## 三句可直接使用

1. 「帮我复核保管合同。」
2. （附实习生交接 ZIP）「这个同学交来的包，帮我打开给律师看。」
3. （附律师终版 ZIP）「帮我验收一下，导出 Excel。」

进入 Skill 时会先简短提示这三种用法。在复核对话中只说「保管合同」或「给我保管合同的复核 HTML」也可启动取件。有 ZIP 时，按包内阶段打开。若自然语言未自动选中本 Skill，在消息开头加 `$contract-review`。

Codex 会分别提供固定的「合同复核工具.html」和本批 ZIP。用 Chrome 或 Edge 打开工具，点「导入已有 ZIP」并选取文件。也可以请 Codex 在本机浏览器代导入。律师终版另有预检报告和可用的 Excel，飞书写入需确认目标及操作。

实习生和律师可以随时「导出当前进度」，重新导入该 ZIP 会回到原复核阶段。「提交给律师」和「导出律师终版 ZIP」分别下载下一阶段使用的独立 ZIP。

## 风险预埋

只有原始样本时，先确认是否启动预埋。Codex 从计划表 v07 读取双方正式规则，盘点正例、负例、不适用和待核，按每条规则、每个正式审查立场至少 6 份不同合同的正例目标补样。每份入选合同提供两立场评测 Word 和逐件报告，整批提供合同类型覆盖总表及待审清单。用户确认文件和目标后才回填「用于评测的合同」，保留已有附件、复用同名同内容文件并回读核验。已有评测 Word 且尚无标注时，默认按现有版本完成初标。需要继续补预埋时可直接说明。[风险预埋提示词](./skills/contract-review/references/风险预埋提示词.md)

## 上传版本与翻转视图

整批上传一份统一标注集，可混用多件合同的单版本及双版本 Word。配对的 Word 用相同文件名主体及对应立场后缀，标注集填写实际文件全名。翻转视图只在两版对应条款原文不同时显示「切换立场」，切换时两栏卡片跟随该条款。原文相同只显示一张中性色原文卡。中栏和右栏按立场分色，单版本合同也适用，整个批次同立场同色。

## 卡片类型和筛选

工作台按主条款、相关性和触发结论展示五类卡片。已有主条款的相关标注区分触发与未触发，全文无主条款的标注区分缺失触发与缺失未触发。实习生和律师提交前均需确认这四类卡片。第五类「普通切片与规则不相关」无需确认，随 ZIP 保留，默认收起，选择同名类型时才列出。具体字段见[标注与导出](./skills/contract-review/references/标注与导出.md)。

实习生中栏与律师右栏各自显示当前可见的卡片数。「整包必审已确认」按整包计算，两个版本共用的通用批注只需确认一次。
